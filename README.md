# Web de PrintsNCode

Este repositorio aloja la web principal de PrintsNCode y su página de enlaces, publicadas en https://printsncode.com/.

- `index.html`: página principal, proyectos y colaboraciones.
- `link/index.html`: enlaces a redes, herramientas, marcas y descuentos.
- `CNAME`: dominio de la web.

El editor visual y el conversor G-code se mantienen en sus propios repositorios.
